# CV Digital Alvita Kalila

Website Curriculum Vitae digital interaktif yang dibangun menggunakan HTML5 semantik dan CSS3 modern untuk memenuhi ujian tengah semester Teknologi Web di Universitas Bani Saleh.

## Fitur
* Layout responsif menggunakan Flexbox dan CSS Grid.
* Navigasi mulus antar bagian.
* Ter-containerisasi menggunakan Docker dan server web Nginx.
